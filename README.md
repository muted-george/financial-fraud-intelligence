# Financial Fraud Intelligence

## Objective

Investigate how statistical methods and machine learning can help identify potentially fraudulent financial transactions.

## Learning goals

- Python fundamentals and software engineering
- Data structures and algorithms
- NumPy and pandas for data analysis
- Probability, statistics and linear algebra
- Machine learning and model evaluation
- Reproducible research, testing and Git

## Project structure

- `data/raw/`: original datasets
- `data/processed/`: cleaned datasets
- `notebooks/`: exploratory analysis
- `src/fraud_project/`: reusable Python code
- `tests/`: automated tests
- `reports/`: findings and project reports
- `models/`: saved models

## Project status

Stage 1: Python foundations.

## Dataset

The planned dataset is the Kaggle Credit Card Fraud Detection dataset. No dataset has been downloaded as part of this setup.
